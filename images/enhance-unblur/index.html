Image Enhancer & Unblur

Two independent image-processing engines for manual verification. Enhancement and deblur never run as one combined pipeline.

Experimental isolation

This build does not replace the existing Image Enhancer & Upscaler. Every run starts from the original uploaded image.

Processing rules

No face reconstruction. No generated facial detail. No automatic upscaling. If deblurring conflicts with facial fidelity, fidelity wins.

Two engines, two purposes

Enhance image is designed for an already usable photograph. It performs conservative same-resolution tonal, color, noise and micro-contrast work without using a generative restoration model.

Unblur image uses a dedicated deblur model, then limits how much of that result is allowed back into the photograph. Detected facial areas are deliberately source-heavy, and the whole image becomes more conservative if the identity guard cannot establish a reliable face map.

This route is intentionally marked noindex while it is under manual verification. The existing production image tools are not modified by this experiment.
