PDF Compressor

Reduce eligible PDF images or optimize PDF structure while keeping processing on your device. The tool reports actual savings after verifying the output.

Choose your compression mode

  • Balanced: moderate compression of eligible images, with existing text and layout preserved.
  • Strong: prioritize smaller files; eligible images may lose more detail.
  • Lossless: optimize structure without reducing image quality. Some PDFs remain the same size.

Privacy and document preservation

PDF processing takes place in your browser. Document contents are not uploaded for compression. Keep the original and review your downloaded result.

The compressor preserves existing selectable text and OCR; it does not add OCR to scanned pages. Unsupported image structures are left unchanged. Signed, encrypted and unsafe documents may be rejected.

If your PDF cannot be compressed

An already optimized PDF may have no further savings. If no smaller verified output is available, the tool returns the original without claiming a reduction.

File size, decoded image size and document complexity can affect processing. Follow the displayed device limit. Cancel and retry if needed; retain a copy of your original file.

Release preparation: Standard and known-capability mobile profiles accept files up to 100 MB. Lower-memory or unknown-memory mobile profiles use smaller limits. Decoded images and document complexity have separate limits. Physical-device checks remain part of release verification.
