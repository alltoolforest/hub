# Static checklist

- All changed files must remain under `documents/edit-pdf/`.
- No Work, other Documents, Images, Calculators, homepage, shared CSS/JS, domain/DNS, branding, privacy, or navigation changes.
- New line insertion must use the current visual list tail.
- Reflow must consume whitespace before moving lower content.
- Overflow must snap to whole text blocks and never split a line.
- Flowed source hit regions must be hidden on their original page.
- Existing following pages must absorb overflow before new pages are appended.
- Cascading page mutation must preflight annotation and geometry safety.
