Privacy

Know what happens to your data.

AllToolForest is designed to use browser-side processing where practical and to disclose when a workflow has different requirements.

Files and inputs

Current local tools process selected files or entered values in your browser unless the individual tool says otherwise. Closing or refreshing a tool may clear unsaved browser state.

Third-party code

Some tools currently load open-source JavaScript libraries or browser models from third-party content delivery networks. Loading those resources can expose ordinary request information such as IP address, browser details and requested resource to the CDN provider. A future production release should self-host critical dependencies where practical.

Accounts and uploads

The current v2 tools do not require an AllToolForest account. Do not assume that every future feature will work this way; any feature that requires server processing should disclose it before use.

Financial, health and career tools

Calculator results are estimates. Health, financial, tax and career outputs are informational and should not be treated as professional advice or guarantees.

Analytics and advertising

This policy must be updated before adding analytics, advertising, cookies or other tracking technologies to production. Those services should not be silently added under this version of the notice.

Device and browser compatibility

AllToolForest is designed for modern desktop and mobile browsers. File size, available memory, browser download behavior and third-party browser capabilities can affect individual tools, especially OCR, large PDFs, HEIC conversion and background removal.

Tool and feature requests

The Request a Tool page can prepare and copy request text locally. If you choose to submit through GitHub, you leave AllToolForest and GitHub’s own account, privacy and data-handling terms apply. AllToolForest does not require your name, phone number or email for the request form.

Questions

A public contact method should be added before commercial launch so users can send privacy or product questions.
