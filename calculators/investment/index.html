Planning estimate only. SIP contributions are modeled at the end of each month and step-ups begin at the selected interval. A constant effective annual return is assumed; market volatility, taxes, fund expenses, exit loads and actual NAV movements are not modeled. Investment returns are not guaranteed.

How to read the result

Lump sum: CAGR is shown because one initial cash flow grows across the full term.

SIP / Step-up SIP: expected annual return is the projection assumption. It is not presented as an observed XIRR.

Inflation-adjusted value estimates future purchasing power in today's money.
